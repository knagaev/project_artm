Пусть gamma = 0.1
тогда правый контекст
yr_1 = x_1

yr_2 = 0.1 * x_2 + (1 - 0.1) * yr_1 
    = 0.1 * x_2 + 0.9 * x_1

yr_3 = 0.1 * x_3 + (1 - 0.1) * yr_2 
    = 0.1 * x_3 + 0.9 * (0.1 * x_2 + 0.9 * x_1) 
    = 0.1 * x_3 + 0.1 * 0.9^1 * x_2 + 0.9^2 * x_1
    = 0.1 * (x_3 + 0.9^1 * x_2) + 0.9^2 * x_1

yr_4 = 0.1 * x_4 + (1 - 0.1) * yr_3 
    = 0.1 * x_4 + 0.9 * (0.1 * x_3 + 0.1 * 0.9^1 * x_2 + 0.9^2 * x_1)
    = 0.1 * x_4 + 0.1 * 0.9^1 * x_3 + 0.1 * 0.9^2 * x_2 + 0.9^3 * x_1
    = 0.1 * (x_4 + 0.9^1 * x_3 + 0.9^2 * x_2) + 0.9^3 * x_1

yr_5 = 0.1 * x_5 + 0.1 * 0.9^1 * x_4 + 0.1 * 0.9^2 * x_3 + 0.1 * 0.9^3 * x_2 + 0.9^4 * x_1
    = 0.1 * (x_5 + 0.9^1 * x_4 + 0.9^2 * x_3 + 0.9^3 * x_2) + 0.9^4 * x_1

И общая формула для правого контекста
