Алгоритм обработки корпуса (или отдельного батча)

1. На вход поступает линейный массив токенов (после токенизации исходного текста), определяем уникальные токены, встречающиеся в массиве - словарь размером W.

2. Задаем требуемое количество топиков T.

3. Создаем вектор окна контекста с затуханием, состоящий из префиксных значений размером C, позиции ведущего токена и суффиксных позиций размером C. Итого размерность (2C + 1), значения коэффициентов контекста инициализируются по формуле gamma * (1 - gamma) ** abs(i - j), i - позиция ведущего токена, j - позиция токена контекста, j = 1..C.

4. Создаем квадратную матрицу Фи размерностью TxW, в ячейке (t, w) вероятность присутствия темы t при наличии токена w. Заполняем случайным равномерным распределением с условием, что сумма по столбцам равна 1 - в столбце вероятности для всех топиков по заданному токену w.

5. Создаем вектор n_t для хранения безусловной частотности топиков в корпусе и заполняем его средним значением (размер корпуса I / количество топиков T).

6. На каждом шаге (далее считаем, что имеем батч I - часть корпуса, которую обрабатываем на этом шаге):

6.1. Поэлементным умножением Фи и n_t (для идентичных топиков) cчитаем матрицу Фи^, как Фи, перевзвешенную по частотности топиков n_t (если топик чаще, то вероятность токенов, имеющих отношение к данному топику, увеличивается) и нормированную.

6.2. Расчет Теты:

6.2.1. Собираем матрицу Фи^_батч, размерностью I x T, которая для каждой позиции в батче получает строку из Фи^ (вероятность пары топиков t - токен w в позиции i).

6.2.2. Формируем трехмерный тензор окон контекста для каждой позиции в батче и каждого топика Фи^_батч_контекст размерностью I x (2C + 1) x T. Он содержит для каждой позиции i двумерную матрицу контекстов этой позиции (значений из Фи^_батч вероятности топика t с контекстом C_i этой позиции c заполнением значением -1 позиций в контексте, выходящих за границы батча). 

6.2.3. Формируем матрицу внимания размерностью I х (2C + 1), состоящую из булевых значений, показывающих используется ли токен в этой позиции - учитываем границы документов (False для не учитываемых в контексте позиций, так как они выходят за границы документа, которому принадлежит ведущая позиция).

6.2.4. Поэлементным умножением (для идентичных позиций) матрицы внимания и вектора окна контекста с последующим нормированием по окну контекста (сумма коэффициентов в окне равна 1) формируется матрица контекста размерностью I х (2C + 1), состоящая из значений коэффициентов контекста в окнах, соответствующих каждой позиции батча с учетом границ документов (нулевые значения для позиций, выходящих за границы документа, которому принадлежит позиция).

6.2.5. Матрица контекста поэлементно (при совпадении позиции i и позиции в окне j) умножается на трехмерный тензор Фи^_батч_контекст - в результате получаем трехмерный тензор Тета_батч_контекст размерностью I x (2C + 1) x T, значениями которого являются вероятности топика t, которую обеспечивает токен w в позиции j контекстного окна i, кроме токена ведущей позиции. 

6.2.6. Матрицу Тета_батч размерностью I x T, значения которой показывают вероятности топика t в позиции i при наличии контекста C_i, но без учета токена ведущей позиции i, получаем суммированием по измерению окна (складываем вероятности всех токенов в окне).

6.3. Расчет матрицы P_ti (полной вероятности топика t в позиции i):

6.3.1. Аналогично 6.2.1. собираем матрицу Фи^_батч, размерностью I x T, которая для каждой позиции в батче получает строку из Фи^ (вероятность пары топиков t - токен w в позиции i).

6.4.1. Матрицу P_ti получаем поэлементным умножением (при совпадении позиции i и топика t) матрицы Фи^_батч и матрицы Тета_батч (у обеих размерность I x T) - то есть, вероятность нахождения топика t в позиции i при условии наличия ведущего токена w (по матрице Фи^_батч) и наличия окружающего его контекста C_i (по матрице Тета_батч), после чего нормируем по измерению T - сумма вероятностей всех топиков в этой позиции 1.

6.4. Пересчитываем вектор n_t_новый частотности топиков путем суммирования матрицы P_ti по измерению I.

6.5. Формируется функция градиента регуляризаторов как градиент суммы регуляризаторов с единицей (для защиты от пустого списка регуляризаторов).

6.6. Новая матрица Фи_новая по результатам шага:

6.6.1. Матрица размерностью W x T рассчитывается на основе P_ti: для этого в строку w суммируются вероятности топиков столько раз, сколько в различных позициях i встречается топик w. 

6.6.2. После этого из данной матрицы вычитается произведение Фи на результат применения функции градиента регуляризаторов к Фи.

6.6.3. Окончательно полученная матрица нормируется по измерению T (сумма вероятностей топиков для заданного токена w равна 1).

7. По окончанию шага полученные новые значения Фи_новая и n_t_новый заменяют значения Фи и n_t и шаг повторяется до сходимости Фи. 

7.1. Для случая батчевой обработки полученное значения Фи_новая дополнительно суммируется с Фи с коэффициентом скорости обучения lr (Фи_новая = Фи_новая * lr + Фи * (1 - lr)).
